# OL3 Aquecedores

Site da OL3 Aquecedores: instalação e manutenção de aquecedores a gás de passagem em São Paulo e Grande SP.

Site estático (HTML + SVG), sem etapa de build. Para ver localmente:

```bash
python3 -m http.server 8000
```

e abra http://localhost:8000.

## Publicação

Pode ser hospedado de graça no GitHub Pages, Netlify ou Vercel apontando para a raiz do repositório.
